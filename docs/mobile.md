# Mobile experience

## Requirements

The existing roadmap calls for mobile, tablet, and desktop support. Planned
enquiry forms must be usable with touch input, visible validation, and no
horizontal overflow. Telephone and messaging links, if added, must be operable
on mobile.

## Current status

The current frontend is a minimal foundation placeholder, not a responsive
product experience. No device or browser testing has been completed.

## Verification plan

When customer-facing layouts are implemented, check narrow phone, tablet, and
desktop viewports; keyboard navigation; readable text and focus states; form
validation; and direct navigation to React Router routes.
