# Eden Homes — UI/UX Design Guidelines

## 1. Design Overview

Eden Homes is a homestay and boating website based in Honnavar, Karnataka.

The website should communicate:

- Comfort and hospitality.
- Nature and coastal beauty.
- Relaxation and peaceful stays.
- Trust and professionalism.
- Easy accommodation and boating enquiries.

### Design Direction

Create a modern, premium tourism website with a warm, natural and welcoming appearance.

The design should feel elegant without being overly complicated.

Use the Dribbble reference below for visual inspiration:

https://dribbble.com/shots/22243004-Alappuzha-Tourism-Website

Use it as inspiration only. Do not directly copy its layout or branding.

## 2. Design Principles

1. Mobile-first responsive design.
2. Clean and uncluttered layouts.
3. High-quality photography.
4. Consistent spacing and typography.
5. Clear navigation.
6. Strong visual hierarchy.
7. Accessible colour contrast.
8. Simple enquiry and contact flows.
9. Consistent components across all pages.
10. Fast-loading and performance-friendly interfaces.

## 3. Colour Palette

Use a natural coastal-inspired palette.

| Colour | Suggested Hex | Usage |
|---|---|---|
| Forest Green | `#244A3B` | Primary brand colour |
| Deep Forest Green | `#19382D` | Headings and footer |
| Warm Cream | `#F7F6F0` | Main background |
| Sand | `#E8E4D7` | Secondary backgrounds |
| Charcoal | `#242D27` | Main text |
| Paper | `#FFFEFA` | Cards and surfaces |
| Terracotta | `#C17B51` | Restrained accents |

These are proposed design colours and can be refined during implementation.

### Colour Usage Rules

- Use forest green for primary buttons and important actions.
- Use warm cream for large background sections.
- Use charcoal for readable text.
- Use sage green for subtle accents.
- Use muted gold sparingly.
- Maintain sufficient contrast between text and backgrounds.

## 4. Typography

Use a combination of elegant headings and readable body text.

Suggested fonts:

| Font | Usage |
|---|---|
| Georgia | Display headings |
| System sans-serif | Body text and interface elements |

### Typography Guidelines

- Use clear heading hierarchy.
- Avoid excessively small text.
- Keep paragraph widths comfortable.
- Use consistent font weights.
- Maintain readable line spacing.
- Use responsive font sizes.

## 5. Layout and Spacing

Use a consistent spacing system throughout the website.

Suggested spacing scale:

- 4px — Tiny spacing
- 8px — Small spacing
- 16px — Standard spacing
- 24px — Medium spacing
- 32px — Large spacing
- 48px — Section spacing
- 64px — Major section spacing

### Layout Rules

- Use consistent content containers.
- Avoid overly wide text sections.
- Maintain balanced whitespace.
- Use responsive grids.
- Align elements consistently.
- Avoid unnecessary visual clutter.

## 6. Navigation Design

### Desktop Navigation

Include:

- Eden Homes logo.
- Home.
- 1 BHK.
- 2 BHK.
- Boating.
- Contact.
- Enquiry or booking action.

### Mobile Navigation

Include:

- Eden Homes logo.
- Hamburger menu.
- Collapsible navigation.
- Clearly visible enquiry action.

Navigation must be consistent across all public pages.

## 7. Homepage Design

The homepage should introduce Eden Homes and encourage visitors to explore its services.

### Sections

1. **Hero Section**
   - Large owner-approved background photograph.
   - Eden Homes branding.
   - Short welcoming headline.
   - Supporting description.
   - Explore Stays and Explore Boating actions.

2. **Introduction Section**
   - Brief introduction to Eden Homes.
   - Verified location and business information.

3. **Accommodation Section**
   - 1 BHK accommodation card.
   - 2 BHK accommodation card.
   - Photographs and short descriptions.
   - View Details actions.

4. **Boating Section**
   - Owner-approved boating photographs.
   - Verified service information.
   - Enquire Now action.

5. **Gallery Section**
   - High-quality photographs.
   - Responsive image grid.

6. **Contact Section**
   - Owner contact numbers.
   - Click-to-call actions.
   - WhatsApp enquiry access.

7. **Footer**
   - Logo and brief introduction.
   - Navigation links.
   - Contact details.
   - Copyright information.

## 8. Accommodation Page Design

Create separate pages for 1 BHK and 2 BHK accommodation.

### Layout

- Property hero photograph.
- Property title.
- Verified description.
- Photo gallery.
- Verified amenities.
- Verified guest capacity.
- Pricing, only when confirmed by the owner.
- Booking enquiry action.

### Enquiry Form

Fields:

- Name
- Phone number
- Check-in date
- Check-out date
- Guest count

The form should be simple, readable and mobile-friendly.

## 9. Boating Page Design

### Layout

- Large boating photograph.
- Boating introduction.
- Verified boating information.
- Available options, if confirmed.
- Photo gallery.
- Enquire Now button.

### Enquiry Form

Fields:

- Name
- Phone number
- Preferred date
- Participant count
- Preferred duration

Do not display unverified prices, packages, duration options or availability.

## 10. Optional Future Owner Dashboard Design

An owner dashboard is not part of the initial release. The following notes are
an optional future direction and require separate owner approval.

### Dashboard Layout

- Sidebar navigation on desktop.
- Collapsible or compact navigation on mobile.
- Dashboard overview.
- Accommodation enquiries.
- Boating enquiries.
- Enquiry details.
- Search and filters.
- Status management.

### Enquiry Status Design

Use consistent visual indicators:

- Pending
- Under Review
- Confirmed
- Rejected
- Cancelled

Status colours must be accompanied by readable labels.

## 11. Buttons and Interactive Elements

### Primary Buttons

- Forest green background.
- White text.
- Rounded corners.
- Clear hover and focus states.

### Secondary Buttons

- Transparent or light background.
- Green border or text.
- Consistent shape and spacing.

### Interaction Guidelines

- Buttons should provide clear feedback.
- Links should have visible interaction states.
- Forms should show validation messages.
- Disabled buttons should look visibly disabled.
- Interactive elements should be easy to tap on mobile.

## 12. Cards and Containers

Use consistent card styling for:

- Accommodation options.
- Boating information.
- Gallery images.
- Enquiry summaries.
- Dashboard statistics.

Guidelines:

- Consistent border radius.
- Subtle shadows where appropriate.
- Balanced internal spacing.
- High-quality images.
- Clear titles and descriptions.

Avoid excessive shadows, gradients and decorative effects.

## 13. Image Guidelines

Photography is an important part of the Eden Homes experience.

Use:

- Genuine accommodation photographs.
- Owner-approved boating photographs.
- Relevant location photographs.
- Consistent image ratios.
- Optimized WebP images where appropriate.

Do not use unrelated stock photographs that misrepresent the actual property or boating services.

## 14. Responsive Design

Follow the mobile-first guidelines in `mobile.md`.

The website must adapt to:

- Smartphones.
- Tablets.
- Laptops.
- Desktop screens.

Requirements:

- No unwanted horizontal scrolling.
- Responsive navigation.
- Flexible image layouts.
- Mobile-friendly enquiry forms.
- Readable typography.
- Consistent spacing.
- Touch-friendly controls.

## 15. Accessibility

- Maintain readable colour contrast.
- Provide meaningful image alt text.
- Label all form fields.
- Support keyboard navigation.
- Use visible focus indicators.
- Avoid communicating information through colour alone.
- Use appropriate semantic HTML elements.

## 16. Design Consistency Rules

- Keep the static HTML pages visually consistent and share CSS and JavaScript behavior.
- Maintain consistent colours and typography.
- Use shared button and card styles.
- Follow a common spacing system.
- Avoid inconsistent border radii.
- Keep public pages visually consistent.
- Keep the owner dashboard visually distinct but aligned with the brand.

## 18. Current design goal

Create a visually appealing, premium and trustworthy digital experience for
Eden Homes. Service pages use verified information only and clearly labeled
photo placeholders until owner-approved photography is supplied. Initial
enquiry forms prepare a WhatsApp message for manual sending using the
owner-provided destination configured in `frontend/js/config.js`; they do not
store requests or confirm bookings.

The website should make visitors feel confident exploring the accommodation and boating services while making enquiries as simple as possible.

The current frontend uses static HTML, CSS, and browser-native JavaScript.
Service enquiry forms prepare a WhatsApp draft for manual sending using the
owner-provided configured destination.
